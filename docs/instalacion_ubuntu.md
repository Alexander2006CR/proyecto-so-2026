# Instalación y configuración del sistema operativo

## Software utilizado

Para el desarrollo del proyecto se utilizó el siguiente software:

- Sistema operativo: Ubuntu Desktop 24.04.4 LTS
- Máquina virtual: Oracle VirtualBox
- Sistema anfitrión: Windows

## Descarga de Ubuntu

Se descargó la imagen ISO oficial de Ubuntu desde el sitio web oficial para realizar la instalación dentro de una máquina virtual.

## Instalación de VirtualBox

Se instaló Oracle VirtualBox en el equipo anfitrión con el objetivo de crear y ejecutar una máquina virtual donde posteriormente se instalaría Ubuntu.

## Creación de la máquina virtual

Se creó una nueva máquina virtual con la siguiente configuración:

- Nombre: Ubuntu Proyecto
- Tipo: Linux
- Versión: Ubuntu (64 bits)
- Memoria RAM: 7710 MB
- Procesadores: 4
- Disco duro virtual: 131.82 GB

## Instalación de Ubuntu

La máquina virtual fue iniciada utilizando la imagen ISO de Ubuntu y se completó el proceso de instalación mediante el asistente.

Durante la instalación se configuró:

- Idioma: Español
- Distribución del teclado: Español
- Tipo de instalación: Normal
- Usuario del sistema
- Contraseña de acceso

## Conclusión

La instalación de Ubuntu se realizó correctamente dentro de una máquina virtual utilizando Oracle VirtualBox. El sistema quedó preparado para la implementación de los servicios requeridos en las siguientes etapas del proyecto.
