# Documentación de Monitoreo del Sistema

## Script de monitoreo

Se creó un script llamado `monitor.sh` para revisar el estado del sistema. Se le dieron permisos de ejecución con `chmod +x`.

## Ejecución

Al correr el script mostró el mensaje "Monitoreo finalizado", confirmando que se ejecuta sin errores.

## Verificación de permisos

Con `ls -lh` se verificó que el script quedó correctamente guardado en la carpeta de scripts con los permisos necesarios para ejecutarse.
