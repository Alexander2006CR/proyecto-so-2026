# Scripts Bash desarrollados

## Script de respaldo (backup.sh)

El script backup.sh fue desarrollado para automatizar el proceso de creación de copias de seguridad del sistema.

Funciones principales:
- Generar respaldos automáticamente.
- Guardar los archivos generados.
- Facilitar la recuperación de información.

## Script de monitoreo (monitor.sh)

El script monitor.sh permite supervisar el estado del sistema mediante la recopilación de información del equipo.

Funciones principales:
- Revisar consumo de CPU.
- Revisar memoria RAM.
- Verificar espacio en disco.
- Registrar información del sistema.
