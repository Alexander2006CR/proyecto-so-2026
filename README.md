## Descripción

Este proyecto fue desarrollado como parte del curso de Sistemas Operativos. Su objetivo es implementar y configurar un entorno Linux utilizando Ubuntu, Apache, MySQL y scripts Bash para automatizar tareas de respaldo y monitoreo del sistema.

## Contenido del repositorio

- `backup.sh`: Script para realizar respaldos de la base de datos.
- `monitor.sh`: Script para monitorear el uso de CPU, memoria RAM y almacenamiento.
- `docs/`: Documentación del proyecto.
- `evidencias/`: Capturas de pantalla utilizadas como evidencia.
